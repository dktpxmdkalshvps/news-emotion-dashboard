# 📊 News Sentiment Insight Dashboard v2.0

**뉴스 감성 분석 대시보드** - 특정 키워드에 대한 뉴스 여론을 자동 수집, 분석, 시각화합니다.

---

## 🎯 프로젝트 목표

- ✅ **여론 모니터링**: 특정 기업/키워드에 대한 뉴스 반응 자동 추적
- ✅ **데이터 기반 분석**: 감성 점수로 정량화된 트렌드 파악
- ✅ **자동화 파이프라인**: 크롤링 → 분석 → 시각화 → 저장 (원클릭)
- ✅ **프로덕션용 코드**: 재시도 로직, 에러 핸들링, 상세 로깅

---

## ⚡ Phase 1 개선사항 (v2.0)

### 🔧 크롤러 강화
- ✅ **자동 재시도**: 네트워크 오류 시 최대 3회 자동 재시도
- ✅ **타임아웃 관리**: 페이지 로드 대기 및 명시적 타임아웃
- ✅ **웹드라이버 안정성**: Exception 처리 및 리소스 정리
- ✅ **상세 로깅**: 크롤링 진행 상황 실시간 추적

### 🧠 감성 분석 고도화
- ✅ **복합어 매칭**: "급등락", "상승세" 등 다중 단어 지원
- ✅ **강도 수정어**: "매우"(1.3x), "약간"(0.8x) 등으로 정밀도 향상
- ✅ **개선된 부정어**: 15자 컨텍스트 윈도우로 더 정확한 감지
- ✅ **신뢰도 점수**: 0~1 범위 신뢰도 지표 추가
- ✅ **160+개 키워드**: 경제/증권 특화 사전

### 📊 시각화 업그레이드
- ✅ **워드클라우드**: 주요 단어를 시각적으로 표현
- ✅ **확장 대시보드**: 5개 패널 (기본 4개 + 워드클라우드)
- ✅ **다크 테마**: 전문성 있는 디자인

### 📝 엑셀 강화
- ✅ **다중 시트**: 전체 / 긍정 / 부정 / 중립 / 통계
- ✅ **자동 스타일**: 색상, 폰트, 정렬 자동 적용
- ✅ **통계 요약**: 긍정율, 평균 점수, 평균 신뢰도 등

### 💻 CLI 인터페이스
- ✅ **사용자 입력**: `python main.py "키워드" --pages 3`
- ✅ **상세 헬프**: `python main.py --help`
- ✅ **로깅 시스템**: DEBUG/INFO/WARNING/ERROR 레벨
- ✅ **설정 검증**: 입력값 자동 검사

## 🧠 감성 분석 알고리즘

### Step 1: 복합어 매칭
```python
"급등락" → 0.0 (상반된 의미 중립화)
"상승세" → +2.0
```

### Step 2: 강도 수정어
```python
"매우 급등" → 3.0 × 1.3 = 3.9
"약간 하락" → -1.5 × 0.8 = -1.2
```

### Step 3: 키워드 매칭 (160+ 사전)
```python
긍정: 급등(3.0), 호재(2.0), 성장(2.0), ...
부정: 급락(-3.0), 악재(-2.0), 손실(-3.0), ...
```

### Step 4: 부정어 처리
```python
"성장 없다" → +2.0 → -2.0 (극성 반전)
"기대하지 않는다" → -2.0 (부정어 감지)
```

### Step 5: 분류
```python
점수 > 0.5    → 긍정
점수 < -0.5   → 부정
-0.5 ≤ 점수 ≤ 0.5 → 중립
```

### Step 6: 신뢰도
```python
신뢰도 = min(1.0, 매칭단어수×0.3 + |점수|×0.1)
```
